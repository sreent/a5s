# Frontend code review checklist

- Lint and unit checks pass before review: a failing check goes back to its author first.
- Every new control can be reached with the keyboard, and has a label for screen readers.
- Colours meet the contrast ratio in both light and dark mode.
- Screenshots of the change are in the pull request's description.

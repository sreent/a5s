# How the backend team releases

1. A pull request merges only once one reviewer from the backend team approves it and every check passes.
2. Releases go out on Tuesdays and Thursdays at 10:00 UK time, from the main branch.
3. A fix for a high or critical bug may go out the same day, once the on-call lead agrees.
4. Write the release note from the pull requests merged since the last release, naming each issue it fixes.
